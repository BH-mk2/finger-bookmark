# FingerBookmark 設計仕様書

本作は、AWS教材PDF等の技術書を快適に読むための、自分専用の技術書特化型PDFリーダー「FingerBookmark」のフロントエンド設計仕様書です。
C++のメモリ管理やレジスタ・ポインタの概念に例えながら、データ構造と状態遷移（ユースケース）を整理します。

---

## 1. コア概念とC++対比

本アプリケーションでは、「しおり（付箋）」「指（一時ピン）」「ペイン（ビューポート）」の3つの概念を完全に独立して管理します。
デバイスや画面幅（PC/スマホ）が異なっても状態を正しく復元できるよう、位置情報はすべて**「ページ番号（pageNumber）」**を論理単位として扱います。

| 概念 | 役割 | C++でのアナロジー | ライフサイクルの特徴 |
| :--- | :--- | :--- | :--- |
| **ペイン (Pane)** | 画面上の分割表示領域。現在表示している「カレントページ」を保持する。 | **プログラムカウンタ (PC)**<br>現在の実行アドレス（ページ番号）を示す。 | **画面上に常に最低1つ存在。**<br>ページをめくるとリアルタイムに値が更新される。 |
| **指 (Finger)** | ユーザーが明示的に「一時的にキープ」した読書ページ。 | **退避用レジスタ / スタック**<br>現在のPCの値を一時保存（push）し、後で復元（pop）するために使う。 | **ユーザーが明示的に追加・削除。**<br>指を挟んだ後にペインをめくっても、指の位置は動かない。 |
| **しおり (Bookmark)** | ユーザーが明示的に名前をつけて貼る「付箋」。 | **不揮発性ストレージ (ファイル)**<br>セーブデータや設定ファイルのように恒久的に残す。 | **ユーザーが明示的に追加・削除。**<br>本全体のメタデータとして残る。 |

## 2. データ構造定義 (TypeScript)

`src/types/reader.ts` に配置予定の型定義です。

```typescript
/**
 * 1. Bookmark（しおり / 付箋）
 * 本の特定のページに貼り付ける静的な付箋データ。
 */
export interface Bookmark {
  id: string;          // 一意の識別子（UUIDなど）
  pageNumber: number;  // 貼り付けたページ番号（1始まり）
  label: string;       // ユーザーが自由に編集できるメモ/ラベル
  createdAt: number;   // 作成日時のタイムスタンプ（Unix epoch ms）
}

/**
 * 2. Finger（指）
 * ユーザーが明示的に「一時的にキープ」した読書ページ。
 */
export interface Finger {
  id: string;          // 一意の識別子
  pageNumber: number;  // 挟んだページ番号（1始まり）
}

/**
 * 3. Pane（ペイン / 表示枠）
 * 画面上の分割エリアを表す。ペイン自身が現在の表示位置（ページ番号）を持つ。
 */
export interface Pane {
  id: string;              // ペイン固有の識別子
  currentPageNumber: number; // 現在表示中のページ番号（ページめくりで動く）
}

/**
 * 4. ReaderState（リーダー全体の永続化状態）
 * アプリ終了・リロード時にそのままシリアライズされてオートセーブされる状態の全容。
 */
export interface ReaderState {
  // 指のプール。IDからO(1)でルックアップ可能な Map (C++の std::unordered_map)
  fingers: Record<string, Finger>;

  // しおりのリスト。ソートや一覧表示のために配列 (C++の std::vector)
  bookmarks: Bookmark[];

  // 画面上のペインリスト。配列の順序が画面の左から右への分割順に対応。
  panes: Pane[];

  // 現在ユーザーが操作対象にしているアクティブなペインのID
  activePaneId: string;
}
```

## 3. ユースケースと状態遷移 (データフロー)

各操作が行われたとき、メモリ（状態）がどのように変化するかを定義します。

### UC-1: ページをめくる
ユーザーが特定のペインで読書を進めたときの処理です。
* **トリガー**: ページネーション（次へ/前へ）ボタンのクリックやスクロールによるページ判定切り替え
* **処理**:
  1. 操作されたペインの `id` を特定する（例: `targetPaneId`）。
  2. `ReaderState.panes` のうち、該当するペインの `currentPageNumber` を新しいページ番号に更新する。
  3. **注意**: 指（`fingers`）の値は**一切変更しません**。
* **C++イメージ**:
  ```cpp
  // レジスタ（現在の閲覧ページ）の上書き
  panes[targetPaneIndex].currentPageNumber = newPage;
  ```

### UC-2: 指を挟む (明示的なページのキープ)
現在の閲覧ページを「指」としてキープする処理です。
* **トリガー**: 「指を挟む」ボタンのクリック
* **処理**:
  1. 現在アクティブなペイン（`activePaneId`）の `currentPageNumber` を取得。
  2. 新しい `Finger` をメモリ上に `new` する。
     * `pageNumber = activePane.currentPageNumber`
  3. 生成した `Finger` を `ReaderState.fingers` に追加する。
* **C++イメージ**:
  ```cpp
  // 現在のレジスタ（ページ）の値をコピーして新しいオブジェクトとしてヒープに退避
  Finger* f = new Finger(activePane.currentPage);
  fingers[f->id] = f;
  ```

### UC-3: 挟んでいる指のページに戻る (復帰)
キープしていた「指」の位置へ、現在のペインを移動させる処理です。
* **トリガー**: 「指リスト」から特定の指をクリック
* **処理**:
  1. クリックされた指（`targetFingerId`）の情報を `fingers` からルックアップする。
  2. 現在アクティブなペイン（`activePaneId`）の `currentPageNumber` を、その指の `pageNumber` で**上書き**する。
  3. PDFビューアをそのページまでスクロール/ジャンプさせる（UI統合レイヤーの処理）。
* **C++イメージ**:
  ```cpp
  // 退避領域からページ番号を読み出し、レジスタに代入（値のコピー）
  activePane->currentPageNumber = fingers[targetFingerId]->pageNumber;
  ```

### UC-4: 指を抜く (明示的な削除)
挟んでいた指が不要になったため、キープを解除する処理です。
* **トリガー**: 「指リスト」の特定の指の「削除（x）」ボタンをクリック
* **処理**:
  1. 対象の `fingerId` を `ReaderState.fingers` から削除（メモリ解放）する。
* **C++イメージ**:
  ```cpp
  delete fingers[targetFingerId];
  fingers.erase(targetFingerId);
  ```

### UC-5: しおり（付箋）を貼る
後から参照するための目印を作成する処理です。
* **トリガー**: 「しおりを追加」ボタンのクリック
* **処理**:
  1. アクティブなペインの `currentPageNumber` を取得。
  2. 新しい `Bookmark` オブジェクトを作成（必要に応じてユーザーがラベルを入力）。
  3. `ReaderState.bookmarks` 配列に `push_back` する。

### UC-6: しおり（付箋）のページにジャンプする
* **トリガー**: しおり一覧から特定のしおりをクリック
* **処理**:
  1. クリックされた `Bookmark` の `pageNumber` を取得。
  2. 現在アクティブなペインの `currentPageNumber` にその値を代入（上書き）する。
  3. **注意**: 指（`Finger`）のリストやデータには一切干渉しません。

### UC-7: ペインを増やす (画面分割)
画面の分割数を増やして、複数のページを同時に見比べられるようにします。
* **トリガー**: 「ペインを追加（画面分割）」ボタンのクリック
* **処理**:
  1. 現在のペイン数（`panes.length`）が最大上限値未満であることを確認（バリデーション）。
  2. 新しい `Pane` オブジェクトを生成する。初期ページは、現在アクティブなペインの位置をコピーするか、あるいはPDFの1ページ目（`1`）とする。
  3. `ReaderState.panes` 配列の末尾に追加する。
  4. 新しく作成したペインのIDを `activePaneId` に設定する（フォーカスの移動）。

### UC-8: ペインを減らす (分割解除)
* **トリガー**: 各ペインの右上にある「閉じる」ボタンのクリック
* **処理**:
  1. 現在のペイン数が **1より大きい** ことを確認する（`panes.length > 1` の不変条件チェック）。
  2. 指定されたペインを `ReaderState.panes` 配列から取り除く（`std::vector::erase` 相当）。
  3. 削除したペインが `activePaneId` だった場合、残ったペインのいずれか（通常は隣のペイン）に `activePaneId` を更新する。

## 4. 不変条件 (Invariant Constraints)

堅牢な状態管理のために、コード実装時に以下の制約をアサーションとして組み込みます。

1. **ペインの最小数保証**:
   `panes.length >= 1` は常に真でなければならない。ペイン削除ロジックの入り口で必ずアサートすること。
2. **アクティブペインの存在保証**:
   `activePaneId` が指すペインは、常に `panes` 配列の中に実在しなければならない。ペインが削除された場合は直ちに `activePaneId` を再割り当てすること。
